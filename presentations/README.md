# CareBuddy presentation

[Download the current launch presentation as PowerPoint](CareBuddy-Launch.pptx) or [PDF](CareBuddy-Launch.pdf).

This 51-slide editable PowerPoint covers the product, target users, prototype, business case, architecture and proposed pilot. The deck retains its original slide content, design and fonts. Its product name is CareBuddy throughout, and the embedded demo uses the refreshed website captures.

Slide 24 includes a clickable “Watch demo video” link to the [mobile walkthrough](https://carebuddy.life/submissions/carebuddy-2026/). The PDF also links the video poster to this page. From the playback page, select **Open the interactive demo** to try the app.
